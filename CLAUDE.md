## Project Overview

Research codebase for **deep generative models using Quasi-Monte Carlo (QMC) sampling**. The core idea: replace random Monte Carlo sampling in latent variable models with quasi-random lattice sequences (Fibonacci, Korobov, Roberts) that provide better coverage of the latent space.

## Architecture

### Core Model: QMCLVM (`models/qmc_base.py`)

The central model. Uses a fixed quasi-random lattice in the latent space (not learned) and trains only the decoder. Key design:
- Lattice points generated by `sampling.py` (Roberts/Korobov/Fibonacci sequences)
- Lattice coordinates mapped through **basis functions** before decoding: `FourierBasis`, `TorusBasis`, `GaussianICDFBasis`, `IdentityBasis`
- Decoder is a standard neural network (see `models/utils.py` `get_decoder_arch()`)
- At inference: compute posterior over all lattice points (no amortized encoder needed)

The simpler, self-contained version is in `mnist_example/qlvm.py` — read this first to understand the QMCLVM design.

### VAE Baseline (`models/vae_base.py`)

Standard VAE with amortized encoder. `posterior()` uses Gauss-Hermite quadrature rather than sampling.

### Sampling (`models/sampling.py`)

Generates QMC sequences:
- `roberts_sequence()` — low-discrepancy sequence based on plastic constant
- `gen_fib_basis()` — Fibonacci lattice
- `gen_korobov_basis()` — Korobov lattice
- `box_muller()` — converts uniform QMC samples to Gaussian

### Training (`train/`)

- `train/losses.py` — evidence lower bound, binary log-likelihood, IWAE loss, energy functions
- `train/train.py` — QMC model training loop
- `train/train_vae.py` — VAE training loop
- Both use Adam optimizer; losses track evidence (not ELBO) as the primary metric

### Data (`data/`)

- `bird_data.py` — HDF5-based bird vocalization spectrograms with conditional factors
- `dynamics_data.py` — motion capture data (AMC format)
- `toy_dsets.py` — synthetic datasets

### Analysis (`analysis/`)

Post-training analysis tools:
- `jacobians.py` — Frobenius norm of decoder Jacobians over the lattice (measures coverage quality)
- `clustering.py` — mean-shift and k-means on torus-periodic latent space
- `geodesics.py`, `tda.py` — topological and geometric analysis of learned representations

## Code Conventions

- Models return distributions (or tensors) from `forward()`; evidence is computed externally in `losses.py`
- Lattice size (`n_lattice`) and latent dimension (`latent_dim`) are the primary hyperparameters
- Conditional models take extra factor inputs; see `qmc_conditional_gerbil.py` for examples
- HDF5 datasets stream from disk — do not assume data fits in memory
